# Altlast

> *Altlast* (German): contaminated ground left behind by past activity.
> Also: the legacy burden nobody wants to be responsible for.

Altlast keeps a register of everything you run and how old it is. It knows the
version, how many releases and how many days behind you are, whether that
version still gets security fixes, and whether anything you carry is being
actively exploited. It never changes anything: it reads, records, and tells you
what deserves an hour of your Saturday.

**Status: early development.**

## Why not just an update notifier?

Tools like What's Up Docker tell you a newer tag exists. Altlast asks whether
the gap matters: is your version still supported, is it past end of life, does
it carry vulnerabilities that are actually being exploited, and how long has
that been true.
